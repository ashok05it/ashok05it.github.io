## 🚀 Quick Start (3 Minutes)

### Step 1: Create GitHub Repository
1. Go to [github.com/new](https://github.com/new)
2. Repository name: **`yourusername.github.io`** (replace `yourusername` with your GitHub username)
3. Make it **Public**
4. Click "Create repository"

### Step 2: Upload Portfolio File
1. In your new repository, click **"Add file"** → **"Upload files"**
2. Upload `index.html` (rename from `index_updated.html` if needed)
3. Upload `README.md` (this file)
4. Click **"Commit changes"**

### Step 3: Enable GitHub Pages
1. Go to **Settings** (repository settings, not account settings)
2. Scroll down to **Pages** section
3. Under "Source", select **main** branch
4. Click **Save**

### Step 4: Access Your Portfolio
Your portfolio is now live at: **`https://yourusername.github.io`**

(It may take 2-3 minutes to deploy)

```html
<div>📱 +91-7418330015</div>  <!-- Your phone -->

```

### Update Color Scheme

Modify the CSS variables at the top of `<style>`:

```css
:root {
    --primary: #6366f1;      /* Main color (currently indigo) */
    --secondary: #8b5cf6;    /* Accent color (currently purple) */
    --accent: #ec4899;       /* Highlight color (currently pink) */
    --dark: #1e293b;         /* Text dark */
    --light: #f8fafc;        /* Background light */
    --text: #334155;         /* Default text color */
}
```

Popular color combinations:
- **Tech Blue:** `#0066ff`, `#00b4d8`, `#00f5ff`
- **Professional Gray:** `#2c3e50`, `#34495e`, `#7f8c8d`
- **Green Modern:** `#10b981`, `#059669`, `#047857`

### Update Experience Section

Find the experience cards and update:


## 📝 Advanced Customization

### Add More Sections

To add a new section, copy this template:

```html
<section id="section-name">
    <div class="container">
        <h2>Section Title</h2>
        <!-- Your content here -->
    </div>
</section>
```

Then add to navigation:
```html
<a href="#section-name">Section Name</a>
```

### Change Animations

Modify `@keyframes` in CSS:
```css
@keyframes slideUp {
    from { transform: translateY(30px); opacity: 0; }
    to { transform: translateY(0); opacity: 1; }
}
```

### Add Images/Photos

Create an `images/` folder and upload images, then reference:
```html
<img src="images/your-image.jpg" alt="Description">
```

## 🆘 Troubleshooting

### Portfolio Not Loading
- Check repository name is `yourusername.github.io`
- Confirm file is named `index.html`
- Wait 3-5 minutes for deployment
- Clear browser cache (Ctrl+F5 or Cmd+Shift+R)
- Check GitHub Pages settings are enabled

### Changes Not Showing
- Commit and push changes to repository
- Wait 1-2 minutes for deployment
- Hard refresh browser (Ctrl+Shift+R)
- Check file is saved properly

### Styling Looks Wrong
- Ensure CSS is in `<style>` tags
- Check no HTML syntax errors
- Test in different browser
- Clear browser cache and cookies

### Links Not Working
- Verify section IDs match nav links (e.g., `#experience`)
- Check email format: `mailto:your-email@example.com`
- Test LinkedIn URL is correct and public
