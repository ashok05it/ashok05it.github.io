# Ashok Kumar - Portfolio Website

A professional, simple portfolio website showcasing expertise in Customer Success Engineering, Enterprise Implementation, and Program Management for MDM/UEM platforms.

## 🚀 Quick Setup (GitHub Pages)

Follow these steps to deploy your portfolio to GitHub:

### Step 1: Create a GitHub Repository
1. Go to [github.com/new](https://github.com/new)
2. Repository name: `yourusername.github.io` (replace `yourusername` with your GitHub username)
3. Make it **Public**
4. Click "Create repository"

### Step 2: Upload Files
1. In your new repository, click "Add file" → "Upload files"
2. Upload both files from this folder:
   - `index.html`
   - Any additional files (images, CSS, etc.)
3. Click "Commit changes"

### Step 3: Enable GitHub Pages
1. Go to your repository **Settings**
2. Scroll to **Pages** section
3. Under "Source", select **main** branch
4. Click **Save**

### Step 4: Access Your Site
Your portfolio is now live at: `https://yourusername.github.io`

## 📝 Customization

### Update Personal Information
Open `index.html` and replace:
- `your-email@example.com` → your actual email
- LinkedIn link with your LinkedIn URL
- GitHub username link with your GitHub URL

### Update Content
All sections are clearly marked in the HTML:
- **Header**: Hero section with name/title
- **About**: Your bio and key metrics
- **Experience**: Job history and responsibilities
- **Certifications**: Your certs and credentials
- **Skills**: Areas of expertise
- **Contact**: Links and CTA

### Customize Colors
Find the `:root` section at the top of the CSS and modify:
```css
--primary: #667eea;      /* Main color */
--secondary: #764ba2;    /* Accent color */
```
